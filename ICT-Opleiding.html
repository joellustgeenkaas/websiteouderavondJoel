ICT-opleidingen

Binnen ICT kun je kiezen voor de opleiding Software Developer of System Engineer. Bij beide richtingen leer je door praktische opdrachten en projecten te maken.

Zo ontdek je welke richting het beste bij jouw interesses en talenten past.

richtingen ICT

Software Developer

Een software developer schrijft code, bouwt programma’s en lost technische problemen op.

System Engineer

Een System Engineer zorgt ervoor dat computersystemen en netwerken goed werken.
